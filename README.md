# 산업연관표 분석 웹앱 (2023년 한국)

작성자: (202511236 · 권현) · 산업조직론 과제물1

한국은행 2023년 산업연관표(연장표, 생산자가격) 투입산출표를 **대분류(33) · 중분류(83) · 소분류(165) · 기본부문(380)** 네 가지로 불러와 브라우저에서 산업연관분석을 수행하는 웹앱입니다. 별도 서버가 필요 없습니다.

## 사용 방법
1. **자료 불러오기**: 분류 버튼 또는 "네 가지 모두"를 누릅니다. 분석 기준 분류를 고릅니다.
2. **원자료 탐색**: 시트를 고르고 코드·산업명으로 행을 검색, 행을 누르면 모든 열 값이 나옵니다(열 검색 가능). 시트별 단위가 표시됩니다.
3. **산업구조**: 총산출, 부가가치율, 중간투입률, 수출비중, 수입의존도, 영향력·감응도계수를 비교하고 CSV로 저장합니다.
4. **시뮬레이션**: (가) 한 산업의 최종수요 변화액 입력, (나) 수출 전체 변화율 입력 → 생산·부가가치 변화.
5. **분류 비교**: 같은 충격을 네 분류에 적용해 결과 차이(통합 편의)를 확인합니다.

## 분석 방법
| 지표 | 식 | 해석 |
|---|---|---|
| 생산유발 | ΔX = L·ΔF, L=(I−Ad)⁻¹ | 국산 최종수요 변화가 유발하는 산업별 생산 |
| 부가가치유발 | ΔV = v·ΔX, v=부가가치계÷총투입계 | 생산 변화에 따른 부가가치 변화 |
| 생산유발승수 | ΣΔX ÷ ΣΔF | 최종수요 1원당 생산 |
| 영향력계수 | L 열합 ÷ 열합 평균 | 1보다 크면 후방연관 큼 |
| 감응도계수 | L 행합 ÷ 행합 평균 | 1보다 크면 전방연관 큼 |
| 수출비중 / 수입의존도 | 수출÷총산출 / 수입계÷총공급계 | 대외 의존 정도 |
