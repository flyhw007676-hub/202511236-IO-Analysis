3. 산업구조 한눈에 보기

단위: 총산출·부가가치 = 백만원, 비율 = %, 영향력·감응도계수 = 계수(평균 1). 머리글을 누르면 정렬됨.

4. 최종수요 변화 시뮬레이션

생산유발계수(L)를 이용해 ΔX = L·ΔF 계산. ΔF는 국산품 최종수요 변화액(백만원, 감소는 음수).

(가) 산업 하나에 금액 입력: 백만원

(나) 수출 전체 변화율: %

5. 분류 수준별 비교

같은 충격(수출 −10%)도 분류를 묶을수록 결과가 달라짐. 불러온 표만 비교됨. 단위: 조원(총산출·생산감소), %.

분석 방법과 한계

국산투입계수 Ad, 생산유발계수 L=(I−Ad)⁻¹(엑셀 값 사용), 부가가치율 v = 부가가치계 ÷ 총투입계, 부가가치유발 ΔV = v·ΔX. 영향력계수 = L 열합÷평균, 감응도계수 = L 행합÷평균. 투입구조 고정·공급제약 없음을 가정한 단기 근사이며, 생산자가격 기준이라 구매자가격과 다름. 자세한 설명은 README.md 참고.
